# Survey Power BI Dashboard

## Project Overview
An interactive Power BI dashboard built to analyze survey responses and identify key trends, patterns, and insights.

## Objective
The objective of this project is to transform survey data into an interactive dashboard that helps users understand response patterns and compare key metrics across different categories.

## Tools Used
- Power BI
- DAX
- Power Query

## Key Features
- Interactive dashboard
- KPI analysis
- Survey response analysis
- Category-based analysis
- Interactive filtering and slicers
- Data visualization

## Skills Demonstrated
- Data cleaning and transformation
- Data modeling
- DAX measures
- Interactive dashboard development
- Business data analysis
- Data storytelling
